# Aplicativo Admin Loja (versão web)

Esta pasta é o aplicativo. O APK só abre o endereço onde ela está hospedada.

## Primeira vez (Netlify)
1. app.netlify.com/drop > envie `anele-app.zip`. Anote o endereço (ex.: https://xxxx.netlify.app).
2. Opcional: Site configuration > Change site name > `anele-app`.

## Atualizar o app depois
1. Abra o MESMO site no Netlify (não use o /drop de novo, ele cria outro site).
2. Aba Deploys > envie o novo `anele-app.zip` (Deploy manually / arraste o arquivo).
3. Em poucos minutos os celulares mostram "Nova versão disponível". Para tornar obrigatória:
   Configurações > Aplicativo > Tornar obrigatória.
